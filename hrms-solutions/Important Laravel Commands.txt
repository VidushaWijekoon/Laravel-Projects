Laraval Commands

🛠️ Project Setup & Maintenance

1.     	laravel new example-app            => Create Laravel App
2.     	php artisan serve 		       => Run Project
3.     	php artisan migrate		       => Run all outstanding migrations
4.     	php artisan migrate:fresh		=> Drop all tables and re-run all migrations
5. 	       php artisan rollback               => Drop single tables and re-run all migrations
6.     	php artisan migrate:status		=> Check the status of each migration
7.     	php artisan db:seed		       => Run the database seeder
8.     	php artisan migrate:fresh --seed	=> Drop all tables, migrate, then seed
9.     	php artisan config:clear		=> Clear the configuration cache
10.    	php artisan cache:clear            => Clear the application cache
11.    	php artisan route:clear            => Clear the route cache
12.    	php artisan view:clear             => Clear compiled Blade views
13.    	php artisan optimize:clear		=> Clear all caches (recommended during dev)
14.    	composer dump-autoload             => Rebuild the class loader after adding/removing files

✅ Steps to Clone & Run a Laravel Project

1.     git clone https://github.com/your-username/your-laravel-project.git	=> clone the project
2.     cd your-laravel-project
3.     composer install
4.     cp .env.example .env 						       => Create env file
5.     php artisan key:generate						       => Generate the key
6.     php artisan migrate
7.     php artisan db:seed
8.     php artisan migrate:fresh --seed
9.     npm install
10.    npm run dev
11.    npm run watch


📦 Code Generation (Scaffolding)

       php artisan make:model Branch -mcf			=>  Model with Migration, Controller, Factory (in one)
15. php artisan make:model ModelName			       	=> Create a new model
16. php artisan make:controller ControllerName		       	=> Create a new controller
17. php artisan make:controller ControllerName --resource	=> Create a resource controller
18. php artisan make:migration create_table_name		=> Create a new migration file
19. php artisan make:seeder SeederName			       	=> Create a new seeder class
20. php artisan make:factory FactoryName			=> Create a new model factory
21. php artisan make:middleware MiddlewareName		       	=> Create new middleware
22. php artisan make:request FormRequestName		       	=> Create a new form request class
23. php artisan make:command CommandName			=> Create a custom Artisan command
24. php artisan make:event EventName			       	=> Create a new event class
25. php artisan make:listener ListenerName		       	=> Create a new listener class
26. php artisan make:job JobName				=> Create a new queued job

🔄 Route & Controller Tools


27. php artisan route:list					       	=> Show all registered routes
28. php artisan route:cache					       	=> Cache all routes for performance
29. php artisan route:clear					       	=> Clear route cache
30. php artisan make:controller SomeController --model=Model		=> Create controller tied to a model


✅ Testing

31. php artisan test			              	=> Run all PHPUnit tests
32. php artisan test --filter=TestName	       		=> Run specific test method or class
33. php artisan schema:dump		              	=> Dump your database schema

🧱 Auth & Breeze/Jetstream/Passport/etc.

34. php artisan make:auth		              	=> (Laravel <6) Scaffold basic auth
35. php artisan breeze:install		       		=> Install Laravel Breeze
36. php artisan jetstream:install livewire		=> Install Laravel Jetstream with Livewire
37. php artisan passport:install	              	=> Install Laravel Passport OAuth

🔐 Queues, Events, and Jobs

38. php artisan queue:work	=> Process jobs in the queue
39. php artisan queue:listen	=> Listen to the queue and run jobs in real-time
40. php artisan queue:restart	=> Restart all workers
41. php artisan queue:failed	=> List failed jobs
42. php artisan queue:retry id	=> Retry a failed job

📅 Scheduler

43. php artisan schedule:run	=> Run scheduled tasks (usually in cron every minute)
44. php artisan schedule:list	=> List all scheduled tasks

🔍 Debugging & Insight

45. php artisan about		=> Displays details about your Laravel installation
46. php artisan env		=> Show current environment
47. php artisan config:cache	=> Cache your config for faster loading (in production)
48. php artisan view:cache	=>Compile all Blade views
